Install Lintel

A faster board for SIT's room booking system, on your phone.

Lintel is an unofficial student project. It is not affiliated with or endorsed by SIT. You need your own SIT account. See the privacy policy.

iPhone or iPad

  1. Install the free Userscripts app and open it once.
  2. In Settings, go to Apps, Safari, Extensions. Turn on Userscripts and allow it on rbs.singaporetech.edu.sg and this site.
  3. In Safari, tap the button below, then tap the Userscripts icon in the address bar and install.
  4. Open the booking site and log in.

Android

  1. Install Firefox.
  2. In Firefox, add the Tampermonkey extension.
  3. Tap the button below and confirm the install.
  4. Open the booking site in Firefox and log in.
Install Lintel

Updates install automatically. To stop using Lintel, remove it from Userscripts or Tampermonkey.
